## 5 加密事实与不可得性（必须先读）

### 5.1 检查结论

| 检查项 | 结果 |
| --- | --- |
| Bundle 总数 | 842 个（APK 内） |
| 加密比例 | **100%**，无一例外 |
| 文件魔数 | `UnityHLDDZ\0`（11 字节，原版为 `UnityFS`） |
| 头部结构 | magic(11) + version(4, BE) + unityVersion + unityRevision + size(i64 BE) + csize + usize + flags(4) |
| flags | 全部 `0x43` = LZ4HC + BlocksAndDirectoryInfoCombined |
| 头部解析 | **成功**，842/842 可正确解析出 size / csize / usize |
| blocksInfo 解压 | **失败**，LZ4 / LZMA / zlib 全部抛错 |
| 暴力扫描 | 对 360 个起始偏移逐一尝试 LZ4 解压，无一命中 |
| 数据块熵值 | 7.67（加密数据特征，明文 LZ4 通常 7.2 以下且有结构） |
| 明文资产 | 仅 369 张 PNG（0.77 MB，图标/启动图/角标）与 1 个 mp4 |
| 结论 | **加解密在魔改的 `libunity.so` 内完成，静态解包无法取得图片与音频二进制** |

### 5.2 已尝试且失败的路径

1. 标准 `UnityFS` 头重建 → 解析失败（字段为大端序，与标准小端不符）。
2. 直接 LZ4 解压 blocksInfo → `LZ4BlockError`。
3. 尝试 LZMA / zlib 解压 → 全部抛错。
4. 在 `libunity.so` 中检索 `UnityHLDDZ` 字符串交叉引用 → 未命中（疑似经 GOT 间接调用）。
5. 在 IL2CPP 元数据 153,356 个方法中检索加解密相关命名 → 加密不在 C# 层。
6. 检索 36,676 条字符串常量中的密钥/魔数 → 无命中。
7. 官方 CDN `hlddz.huanle.qq.com/res/` → 仅开放 70 个活动图标 URL，不含牌面与音频。

### 5.3 结论与处置

| 项 | 结论 |
| --- | --- |
| 图片二进制 | **不可得** |
| 音频二进制 | **不可得** |
| 资源命名与结构 | **完全可得**（本册第 2～4 章即基于此） |
| 处置 | 按 6 章矢量重绘 + 合成音效；若需像素级一致，须动态调试 dump 或由产品提供素材包 |

## 7 资源引用与加载规范

1. **本地化**：所有图片资源放在 `src/static/game/`，禁止远程 URL。
2. **按需生成**：牌面不存 54 张 PNG，运行时按 6.1 参数用 Canvas 生成，减少包体。
3. **预加载**：进入牌桌前预生成 54 张牌面纹理，避免首帧卡顿。
4. **音效单例**：统一 `DdzAudio` 单例，禁止页面内 `new Audio()`。
5. **失败降级**：
    1. 牌面纹理生成失败 → 纯色卡片 + 文字点数。
    2. 音效播放失败 → 静默跳过，不弹提示。
    3. WebGL 不可用 → 降级 Canvas 渲染。
6. **体积约束**：`static/game/` 总体积不得超过 1.5 MB（Phaser 库除外）。
7. **缓存**：Phaser 库与牌面纹理使用 `Cache-Control: max-age=31536000`。
